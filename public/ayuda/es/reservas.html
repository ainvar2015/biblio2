Reservas

Cola de reservas, límites y notificaciones de disponibilidad

Cuando un libro no está disponible, la aplicación gestiona una cola de reservas por orden de llegada.

Cómo funciona la cola

  1. Un usuario solicita la reserva de un libro prestado.
  2. La reserva queda en cola con su fecha, respetando el orden de solicitud.
  3. Cuando el libro se devuelve, el sistema notifica al siguiente en la cola y la reserva queda disponible para recoger.

Límites y avisos

  • Cada usuario tiene un número máximo de reservas simultáneas configurado por la biblioteca.
  • El sistema envía notificaciones por email cuando una reserva está lista para recoger.

Gestión

Desde el listado de reservas puede cancelar una solicitud o marcarla como entregada cuando el libro se recoja.

Si un socio no recoge el libro en el plazo indicado, cancele la reserva para que pase al siguiente de la cola.
