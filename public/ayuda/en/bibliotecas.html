Libraries

Library management and active library selector

The application supports multiple libraries under one installation. This module manages each of them.

What you can do

  • View the list of registered libraries.
  • Add a new library with its details (name, address, contact).
  • Edit an existing library's details.

Switching the active library

Super administrator users see a library selector in the top bar or in this module: everything you add (books, loans, users) will be linked to the selected library.

Before working, check you are in the right library: catalogues and loans are separated per library.
