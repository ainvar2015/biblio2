Reservations

Reservation queue, limits and availability notices

When a book is unavailable, the application manages a reservation queue in request order.

How the queue works

  1. A user requests a reservation for a borrowed book.
  2. The reservation joins the queue with its date, preserving request order.
  3. When the book is returned, the system notifies the next person in line and the reservation becomes ready for pickup.

Limits and notices

  • Each user has a maximum number of simultaneous reservations set by the library.
  • The system sends email notifications when a reservation is ready for pickup.

Management

From the reservations list you can cancel a request or mark it as picked up when the book is collected.

If a member does not pick up the book within the stated period, cancel the reservation so it passes to the next person in line.
