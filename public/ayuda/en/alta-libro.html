Add a book

Manual registration or automatic by ISBN

Register a new book in the catalogue, manually or by ISBN with autocomplete.

Adding by ISBN (recommended)

  1. Under Add New → Add a book, type the ISBN in its field.
  2. The application queries an external database and fills in title, authors, publisher, genre and cover automatically.
  3. Review the suggested data and correct whatever is needed.
  4. Save the book.

Manual entry

  1. Fill in the form: title, ISBN, authors, publisher, genre and synopsis.
  2. Upload a cover if you have one; otherwise the book will use the placeholder image.
  3. Save.
If autocomplete cannot find the ISBN (older or very local works), complete the form by hand: manual entry is always available.
Make sure the authors and publisher already exist in the catalogues; if not, create them first under Add New → Authors, publishers & genres.
