Settings

Library settings, loan rules and email

General configuration of the application and the active library.

What is configured here

  • Active library details (name, address, contact, logo).
  • Loan rules: default loan days and per-user reservation limits.
  • Email sending configuration (reminders and reservation notices).
  • General application parameters.
Changes to loan days affect new loans only; already recorded loans keep their return date.
Configuration applies per library: if you manage several, review the settings in each one.
