Actions on a loan

ActionWhat it does
ReturnRecords the actual return and frees the book.
+7 daysExtends the return date by one week.

History

The history view lists all completed loans with the actual return date, useful for usage statistics.

The tracked date fields are fecha_prestamo and fecha_devolucion (expected); the actual return is stored in fecha_devolucion_real, with any incident noted in notas.
