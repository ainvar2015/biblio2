Edit a book

Modifying a book's data and cover

Modify an existing book's data: title, authors, publisher, genre, synopsis and cover.

Editing workflow

  1. Go to Edit → Edit a book and search for the book (by title or ISBN).
  2. Select it to load the form with its current data.
  3. Adjust the fields you need. You can pick multiple authors for collective works.
  4. If you upload a new cover, it will replace the previous one.
  5. Save the changes.

Edit vs. add

The form automatically distinguishes edit mode from add mode depending on context: coming from Edit, you will see the data loaded and the button will update rather than create a new record.

Covers follow the same 3 cases as the catalogue: real file, registered but missing, or unregistered (no-imagen.jpg is shown).
